OpenCodex Desktop 首个公开预发布版本。

- 提供 Windows x64、macOS Apple Silicon 和 Intel 安装包。
- 修复恢复原生 Codex 后，重装桌面版无法重新连接代理的问题。
- 保留 Codex 在连接代理期间新增的设置。

Windows 基础功能已通过实机验证。发布前，三个平台均需通过自动构建、桌面回归和打包资源验收。
macOS 窗口与托盘仍需实机验证；Mac 安装包采用 ad-hoc 签名，尚未进行 Apple 开发者签名和公证。

升级前请从托盘退出旧版。Windows 安装时选择“安装前卸载”，保留应用数据。
无需删除 `.codex` 目录或重新登录 Codex。

---

First public preview of OpenCodex Desktop, with Windows x64 and macOS Apple Silicon/Intel installers.
Fixes reconnection after reinstalling when a restored Codex recovery journal remains, while preserving newer client settings.
Windows basic functionality has been tested manually. Mac window/tray behavior still needs hands-on testing;
Mac builds use ad-hoc signing without Apple Developer ID signing or notarization.
Quit the existing app before upgrading and retain application data during the Windows uninstall step.
