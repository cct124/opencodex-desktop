# OpenCodex Desktop 0.1.3

## 中文

- 同步上游稳定版 OpenCodex **2.57.0**，保留桌面窗口、托盘、持久配置和固定代理端口。
- 带入上游的按提供方审批模型配置：在管理面板的提供方 JSON 编辑器中设置 `autoReviewModel`，或使用 `autoReviewModelOverrides` 为单个模型设置例外。目前没有专门的下拉框；目标模型必须在同步后的目录中存在。
- 按上游稳定性修复将内置 Bun 固定为 **1.4.0**，附带对应的原始许可证；打包上游新增的远程工作区辅助程序源码。
- 升级前从托盘退出旧版并保留应用数据，再安装新版。此次更新不会自动替用户选择审批模型。
- macOS 安装包仍为 ad-hoc 签名，未作 Apple 公证。

验证范围：桌面回归、配置恢复与固定端口生命周期、GUI 构建和 JSON 编辑保存测试已通过。本地完整上游测试未全量通过，存在超时和环境／上游版本线检查差异；其中两项审批管理测试受 Fake-IP DNS 影响，按维护者选择不再重跑。本版本不声称完整上游测试全绿，发布仍以三个平台的桌面打包验收通过为条件。

## English

- Sync the **OpenCodex 2.57.0** stable release while retaining desktop windows, tray controls, persistent configuration, and the saved proxy port.
- Include upstream provider-scoped approval reviewers through the dashboard's raw provider JSON editor: `autoReviewModel` and per-model `autoReviewModelOverrides`. There is no dedicated picker; targets must resolve in the synchronized catalog.
- Follow upstream's stability pin to bundled **Bun 1.4.0**, include its original license, and package upstream's new remote workspace helper sources.
- Exit the previous app from its tray before upgrading and retain application data. This update does not choose a reviewer automatically.
- macOS bundles remain ad-hoc signed and are not notarized by Apple.

Validation scope: desktop regressions, configuration restoration and saved-port lifecycle, GUI build, and JSON editor tests passed. The complete upstream suite did not pass locally due to timeouts and environment/upstream version-line checks. Two approval-management tests were affected by Fake-IP DNS and will not be rerun for this release at the maintainer's direction. This release does not claim a fully green upstream suite; publication still requires desktop package verification on all three platforms.
