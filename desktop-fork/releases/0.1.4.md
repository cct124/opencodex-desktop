# OpenCodex Desktop 0.1.4

## 中文

- 同步上游稳定版 **OpenCodex 2.63.0**，修复开启代理后原生模型列表缺少 **GPT-6 Sol / Luna** 的问题，带入上游最新模型元数据与代理修复。
- 继续使用本 fork 的桌面壳：关闭窗口驻留托盘，保留停止并恢复原生、仅恢复原生、重新接回代理三种操作，以及持久配置和固定代理端口。
- 本 fork 的桌面源码移至 `desktop-fork/`，上游新加入的 `desktop/` 原样保留，方便以后同步和评估。安装包仍构建我们的桌面版；应用身份、数据目录和用户配置不因源码目录调整而迁移。
- 保留原生 Codex 的 HTTPS/SSE 兼容路径，同时采用上游对第三方 WebSocket 端点的限制。内置 Bun 仍为 **1.4.0**。
- 升级前从旧版托盘选择“退出应用并恢复原生 Codex”，保留应用数据，再安装新版。若 Codex 仍显示旧模型列表，完整退出并重新打开一次 Codex 以刷新已缓存目录；无需重新填写提供方密钥。
- Windows、Apple Silicon Mac 和 Intel Mac 安装包由同一提交构建，校验后才发布。macOS 包仍为 ad-hoc 签名，未作 Apple 公证。

验证范围：根目录与桌面 TypeScript 检查、模型目录和管理边界 390 项测试、同步/传输/测试布局与文件大小约束 223 项测试、桌面回归 33 项测试、Rust 8 项测试、GUI 63 项测试、GUI 构建与国际化检查、文档构建、结构检查和隐私扫描通过。平台不适用的用例保持跳过。本次未运行完整上游测试套件，未使用真实模型账号发送付费请求；跨平台安装包与内置运行时验证由发布流水线执行。

## English

- Sync **OpenCodex 2.63.0** and its native **GPT-6 Sol / Luna** catalog fix, model metadata, and proxy updates.
- Retain this fork's desktop shell: close to tray, native stop/restore/reconnect controls, persistent settings, and the saved proxy port.
- Move the fork shell to `desktop-fork/` and retain upstream's new `desktop/` tree unchanged for future synchronization and evaluation. The installers still build our shell; application identity, data paths, and user settings do not migrate with the source directory.
- Keep native Codex on the desktop's HTTPS/SSE compatibility path while adopting upstream's restrictions on third-party WebSocket endpoints. Bundled Bun remains **1.4.0**.
- Exit the previous version from its tray with native Codex restoration, retain application data, then install this version. If Codex still shows a cached model list, fully quit and reopen Codex once. Provider keys do not need to be entered again.
- Windows, Apple Silicon macOS, and Intel macOS packages are built from the same commit and verified before publication. macOS bundles remain ad-hoc signed and are not notarized by Apple.

Validation: root and desktop TypeScript checks; 390 catalog/management tests; 223 synchronization, transport, layout and size-regression tests; 33 desktop tests; 8 Rust tests; 63 GUI tests; GUI build/i18n checks; documentation build; structure checks; and privacy scan passed. Platform-inapplicable cases remain skipped. The full upstream suite was not run, and no paid requests were sent through real model accounts. The release workflow validates installers and bundled runtimes on all three target platforms.
