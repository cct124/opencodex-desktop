修复重启 OpenCodex Desktop 后，Codex 仍连接旧端口而导致请求或上下文压缩失败的问题。

- 持久保存桌面代理监听端口，重启、退出再打开、配置导入和崩溃恢复均保持同一地址。
- 升级时沿用旧连接记录中的代理端口；恢复原生配置后仍保留已保存的监听端口。
- 端口被占用时明确提示，保留连接选择和 Codex 配置，不自动切换地址。

升级前请从托盘退出旧版，安装时保留应用数据。若旧任务已缓存先前失效的端口，升级后先完整重启一次 Codex；以后正常重启桌面代理无需再重启 Codex，中断的请求重试即可。

Fixes failed requests and compaction when Codex keeps a proxy URL after OpenCodex Desktop restarts.

Persistent installations now retain their loopback port across restarts, imports and crash recovery, migrating the previous endpoint from older connection records. An occupied port produces a clear error instead of silently changing the endpoint or taking over another listener.

Quit the old desktop app before upgrading and retain its application data. Restart Codex once if an existing task already cached a stale address; subsequent proxy restarts reuse the same endpoint. Interrupted requests can be retried.
