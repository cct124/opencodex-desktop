# M2：托盘与进程生命周期

日期：2026-09-11。验证平台：Windows x64，实际 Tauri / WebView2 窗口。

## 当前交付

- 注册 Tauri 官方单实例插件；再次打开程序会显示原有窗口，不再启动一个后端。
- 关闭窗口隐藏到系统托盘，代理继续运行。托盘左键打开主窗口，右键菜单提供状态、启动、停止、重启、控制页、日志和退出。
- 停止代理保留应用与托盘；重启先等待旧后端完成请求排空、退出和回收，再启动新后端；退出应用优先于排队中的重启。
- 托盘和本地控制页接入原生 `ocx stop`、`ocx restore`、`ocx restore back` 对应操作。后两项保持代理运行，单独显示 Codex 当前路由和切换状态；停止或退出等待已开始的切换完成。重启保留已启用的 Codex 代理路由。
- 异常退出显示控制页和错误信息，提供手动重试，不自动无限重启。一次重试最多启动一个后端，界面根据进程状态禁用无效操作。
- 同一个应用会话内保留提供方和模型等开发设置。完全退出后再打开仍创建新的独立会话，保留 M1 的真实配置隔离边界。
- 系统服务、开机启动、原有托盘、全局更新与集成切换入口继续由开发预览保护拦截；桌面生命周期操作从原生托盘和本地控制页进入。

## 实现边界

变更集中在 `desktop/`；本阶段没有修改上游代理业务代码。

Rust 的 `lifecycle.rs` 负责启动、停止、重启和退出之间的状态转换；`backend.rs` 的每个后台线程持有唯一的子进程句柄。事件带启动序号返回 Tauri 主线程，旧进程的延迟事件不能更新新进程状态，窗口与菜单操作不持有状态锁。

继续复用项目内 Bun、上游 CLI、进程身份签名和 `/readyz` 检查。关闭通过 stdin 进入上游 SIGINT 排空与恢复流程。开发预览的请求排空时间最大 60 秒，已开始的路由命令最多等待 45 秒，额外保留清理时间；超过外层 130 秒预算只终止自己持有的子进程，并报告失败。强制终止不等价于配置恢复成功。

恢复与接回通过独立子进程调用项目内 CLI，继承已隔离的环境，不绕过上游进程及用户身份检查。Windows 下将 Rust 规范化产生的扩展路径前缀转换为同一目录的常规写法，避免 PowerShell 5.1 的 `Add-Type` 在扩展格式 TEMP 路径下失败；实际配置目录仍位于开发会话内。

托盘使用 Tauri 自带能力。新增依赖固定为官方 `tauri-plugin-single-instance` 2.4.4，锁文件只增加该插件及其 Windows 平台依赖；原有 Tauri 版本保持 2.11.2。

依赖和权限检查：核对插件官方来源与 Windows 实现；第二次启动传入的参数和工作目录均不执行。宿主命令仍只允许本地 `launcher` 窗口，动作名称使用固定枚举列表，日志路径来自本应用会话。远程管理页没有宿主操作权限。故障注入仅编译进 debug 构建的显式 smoke 参数，没有添加管理 HTTP 接口或网页测试命令。

## 复现

从仓库根目录构建与测试：

```powershell
& "$env:USERPROFILE/.cargo/bin/cargo.exe" test --offline --locked --manifest-path desktop/src-tauri/Cargo.toml
& "$env:USERPROFILE/.cargo/bin/cargo.exe" build --offline --locked --manifest-path desktop/src-tauri/Cargo.toml
& .\node_modules\bun\bin\bun.exe x tsc --project desktop/tsconfig.json
```

先从托盘退出已有开发实例，再在 `desktop/` 运行：

```powershell
& ..\node_modules\bun\bin\bun.exe test tests/runtime.test.ts tests/profile.test.ts tests/routing.test.ts
& ..\node_modules\bun\bin\bun.exe run scripts/native-smoke.ts
& ..\node_modules\bun\bin\bun.exe run scripts/native-smoke.ts --startup-stop
& ..\node_modules\bun\bin\bun.exe run scripts/smoke.ts --parent-eof
& ..\node_modules\bun\bin\bun.exe run scripts/smoke.ts --parent-eof --occupied-port
```

测试结果写入忽略的 `.tmp/desktop/session-*/smoke-result.json`，退出状态写入 `desktop-status.json`，日志按每次后端启动分别保存。

`--occupied-port` 会临时绑定 10100，需该端口空闲；若已由真实服务占用，测试直接报错，不停止该服务。验证结束会清理测试自身的监听器。隐私扫描首次在受限环境遇到 Bun 调用 Git 的 `EPERM`，之后在正常权限下执行通过。
